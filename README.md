# Star-topology
Project Overview
This project includes:
1 Layer 3 Core Switch, 
3 Access Switches, 
1 Branch Router, 
1 ISP Router, 
Departmental PCs, 
Simulated internet server


The layer 3 Core Switch performs:

Inter VLAN routing, 
Routing between the internal VLANs, 
Layer 3 connectivity to the Branch Router

                                     Network Structure:
                    ISP Router
                        |
                  Branch Router
                        |
                   Core Switch
                  /     |     \
                 /      |      \
            Access SW1 Access SW2 Access SW3
                |          |          |
               PCs        PCs         PCs

A star topology enterprise network built in Cisco Packet Tracer using a Layer 3 Core Switch connected to three Access Switches. Each access switch represents the same departmental VLAN structure, creating a multi switch enterprise environment.
